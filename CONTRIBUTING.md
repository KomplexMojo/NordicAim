# Contributing

NordicAim is developed by its owner, and the source is published for transparency, not as an open source project.
**Code pull requests are not accepted.** Under [LICENSE.md](LICENSE.md) you may read the code and run it for
noncommercial use, but not modify or redistribute it.

What helps most:

- **Issues.** Report a wrong score, a confusing screen, or a feature you need. A target photo helps; check it carries no
  location you would rather keep private.
- **Feature requests.** Say what you are trying to do at the range or in coaching. Requests from supporters are weighed
  first.

By submitting an idea, description or example in an issue, you agree the owner may use it freely and without credit or
payment to you.
