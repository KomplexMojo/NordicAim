# Nordic Aim: user manual (starter)

This is where instructions live that are not on the app's screens. It is a starting point; add sections as the app grows.

## Attach the summary image to a Garmin Connect activity

The app does not talk to Garmin (it never connects to any service). The summary image is attached by hand:

1. On the results screen tap **Share**, then in the share sheet choose **Save Image**.
2. Open the Garmin Connect app.
3. Open the activity (usually the most recent).
4. Tap the camera icon and choose the saved image.
